# Barcode Scanner

Terms used to describe barcode scanning and result selection in this application.

## Scanning

**Scan**:
One completed attempt to read barcodes from an imported image or selected screenshot region.

**Visual order**:
The order of barcode results from top to bottom and then left to right in the source image.

**Code 128 auto-copy**:
The productivity behavior that places the first Code 128 result in visual order on the clipboard after a successful scan.
